## 🌟 Welcome to LeetCode Club

**LeetCode Club – Haridwar University** is a student-led coding and problem-solving community designed to encourage programming excellence, logical thinking, collaboration and continuous learning.

We believe that becoming a good programmer is not just about writing code. It is about understanding problems, developing logical thinking, exploring efficient solutions and learning together.

Our community provides a platform where beginners and experienced programmers can connect, practice, share knowledge and grow together.

> Our vision is to build a strong coding culture at Haridwar University, one problem at a time.

---

## 🎯 Our Mission

Our mission is to make coding and problem-solving an active part of student life.

We aim to:

- Build strong Data Structures & Algorithms fundamentals.
- Encourage daily coding and consistent practice.
- Develop logical and analytical thinking.
- Organize coding challenges and programming contests.
- Promote peer-to-peer learning and collaboration.
- Help students prepare for technical interviews.
- Encourage participation in hackathons and technical competitions.
- Build a supportive developer community.

## 🧩 How to Solve a Problem

Every member is encouraged to follow this approach:

1. Understand the problem statement.
2. Identify the input and constraints.
3. Think of a brute-force solution.
4. Find an optimized approach.
5. Implement the algorithm.
6. Test different edge cases.
7. Analyze time complexity.
8. Analyze space complexity.
9. Explain what you learned.

**Remember: Understanding the solution is more important than simply submitting it.**

## 🤝 How to Contribute

We welcome meaningful contributions from students.

### Step 1 – Fork the Repository

Click the Fork button on GitHub.

### Step 2 – Clone Your Repository

```bash
git clone https://github.com/YOUR-USERNAME/LeetCode-Club.git
```

### Step 3 – Create a New Branch

```bash
git checkout -b feature/your-contribution
```

### Step 4 – Add Your Code

Add your solution to the appropriate topic and language folder.

### Step 5 – Commit Your Changes

```bash
git add .
git commit -m "Add array problem solution"
```

### Step 6 – Push Your Changes

```bash
git push origin feature/your-contribution
```

### Step 7 – Create a Pull Request

Submit your Pull Request for review.

Our community can review and discuss contributions before merging them.

## 📝 Standard Solution Format

Please use a consistent format for every programming solution.

```text
Problem Name:
Two Sum

Platform:
LeetCode

Problem Link:
https://leetcode.com/problems/two-sum/

Difficulty:
Easy

Topic:
Array / Hash Map

Approach:
Brief explanation of the logic.

Time Complexity:
O(n)

Space Complexity:
O(n)

Language:
Python
```

Add your implementation below the details.
